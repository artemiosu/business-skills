# Evidence-to-forecast workflow

## 1. Frame and collect

Write a brief: decision, actor, domain, geography, horizon, adoption unit, exclusions, as-of date, and stakes. Decompose “trend” into capability, diffusion, and value capture. Choose historical reference classes before the inside view and record selection bias.

Add budget/runway, loss tolerance, required return, alternatives and opportunity cost. Pre-register a candidate universe/inclusion rule and a balanced confirm/disconfirm search budget. Stop at source saturation or a declared resource limit, not an arbitrary citation count.

Search confirming and disconfirming query families across: benchmarks and failures; cost and switching economics; repositories/jobs/workflows; paid adoption/retention/churn; supply chain/capital/regulation; cancellations/incidents/substitutes. Prefer primary records. A signal is atomic: one observation, event date, lane, and `independence_group`. Syndicated stories or one shared dataset count once.

Look for lead–lag chains: component cost → experimentation → workflow integration → budget → organizational redesign. “No evidence found” is not “evidence of absence” unless coverage and expected observability are specified.

## 2. Score evidence, not excitement

Score each 0–5: `reliability`, `independence`, `leadingness`, `magnitude`, `persistence`, `breadth`, `economics`, and `bottleneck_relief`. Separately score penalties: `hype`, `fragility`, and `missingness`.

The composite is a prioritization index, not probability:

`100 × weighted_positive / (5 × positive_weight_sum) − penalty_points`, clamped to 0–100.

Use the bundled config. Vary material weights ±25%; label rank changes as weight-sensitive.

## 3. Anti-hype gate

Ask: adoption or attention? tiny denominator? dependent sources? benchmark-to-workflow gap? subsidy-dependent economics? visible churn/security/regulatory/integration costs? easy incumbent response? expected observations if false?

Quarantine as “monitor” when fewer than three independent lanes/groups exist, critical fields are missing, or all strongest signals come from interested parties.

## 3a. Adoption, timing, and capture gates

Map awareness → trial → pilot → paid production → retained → expanded, with distinct denominators/cohorts, buyer vs user, paid status, production status, retention window, and procurement/integration cycle. Map readiness for technology, cost parity, complements, regulation, buyer urgency/budget, distribution, and financing; compare time-to-market/revenue with runway.

For capture, identify customer/user/payer, job-to-be-done, willingness-to-pay, gross margin/unit economics, acquisition/payback/retention where applicable, complement owners, bargaining power, commoditization, platform dependencies, incumbent response, defensibility, and reachable bottom-up market. Run the premortem: “the trend succeeds but this entrant fails.” A real trend that fails timing or capture remains `MONITOR`, not `PASS`.

## 4. Hypothesis and council

Each claim needs population, metric, threshold, date, mechanism, assumptions, reference class/base rate, evidence for/against, alternatives, beneficiaries, bottlenecks, indicators, kill criteria, resolution source, probability interval, and a bounded learning action. Use conditional forecasts for pivotal dependencies.

Run eight analytic lenses independently—not fictional real experts:

- Venture: timing, market structure, financing reflexivity.
- Foresight: system transition, horizons, scenario diversity.
- Economics: incentives, complements, substitution, surplus capture.
- Product: user problem, workflow fit, retention, distribution.
- Data science: validity, leakage, dependence, robustness, base rates.
- Intelligence: competing hypotheses, source quality, indicators.
- AI safety/agent design: misuse, autonomy, evaluation, controls, externalities.
- Entrepreneurship: wedge, access, learning speed, survivability.

Each writes a sealed first-pass memo with verdict (`support|oppose|uncertain`), evidence IDs, objection, crux, requested test, conflict disclosure, and confidence. Only then cross-examine and synthesize. Preserve disagreement; never average correlated role confidences.

## 5. Counterfactuals, scenarios, action

Remove the vivid signal; remove the leading vendor; reverse causality; test a macro/regulatory/measurement alternative. Build stalled/base/accelerated scenarios around two uncertain drivers, with causal chains, signposts, probability ranges, implications, and actions.

Stage commitments: watch → cheap probe → pilot → scale. Precommit transition thresholds. For each action record cost/duration, payoff ranges, expected value assumptions, regret, value of information, reversibility, and opportunity cost. Specify monitoring cadence, latency, source, owner if known, trigger→action mapping, expiry, cost, and stop rules.

## Output quality gate

Do not finish without cutoff, lineage, counterevidence, base rate or admitted absence, falsifiable forecasts, anti-hype result, unresolved cruxes, decision implications, monitoring triggers, and limitations.
