# Support

- Usage question or unexpected result: start a GitHub Discussion.
- Reproducible bug: use the bug report issue form.
- New workflow idea: use the skill proposal form.
- Security concern: follow [SECURITY.md](SECURITY.md), never disclose sensitive details publicly.

Before opening a report, use the latest release, run `python3 scripts/validate_repository.py`, and search existing issues. This community project provides no guaranteed response time or professional business advice.
